# ADR-002：当前执行工具是 Guardrails，不是 Sandbox

状态：Accepted

## 背景

v0.2 使用 Shell 黑名单、Python AST 检查和字符串前缀路径判断来提供安全能力。这些机制可以被动态导入、变量路径和其他执行方式绕过，也会误杀合法命令。

## 决策

- 删除“内置安全沙箱”的表述
- 保留工作目录边界作为路径 Guardrail
- 对写文件与执行工具增加 Harness 级审批
- Python 在独立子进程中执行并设置超时
- Shell 默认使用 argv，不启用 `shell=True`
- 真正的安全隔离推迟到容器/虚拟机阶段

## 理由

Prompt、关键词黑名单和 AST 检查不是安全边界。把它们称为 Sandbox 会制造错误信心。对当前本地学习项目，明确的能力审批和真实的行为测试比继续堆黑名单更有价值。

## 后果

- `run_python` 仍可执行任意用户批准的代码
- 审批不能替代隔离
- 后续若需要执行不可信代码，必须增加 OS 级隔离和资源限制
