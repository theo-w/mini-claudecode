# M1.10 Public Learning Demo Specification

- Spec ID：`m1.10-public-demo`
- 状态：In Progress
- 日期：2026-10-29
- 里程碑：M1.10
- 关联 ADR：ADR-004（只读投影）
- 关联 Baseline：无

## 1. 背景与问题

M1.9 的 Dashboard 已经能通过“从零建造”和“乐高实验”独立教学，但页面默认仍会请求 `dashboard/data.json`。该文件被 Git 忽略，可能包含真实 Prompt、工具 Observation 与最终回答，不能直接公开。

如果把现有页面原样部署到 Render：

- 公开仓库中没有 `data.json`；
- 真实解剖、任务故事、Loop 回放、乐高拆解和 A/B 对比都不可用；
- 导航仍展示 5 个不可用入口，访客容易把“没有公开真实 Trace”误解为“Demo 坏了”。

因此需要一个明确、可复现的公开展示模式：保留两个无需真实数据的交互实验，并诚实说明真实 Trace 仅供本地使用。

## 2. 目标

- 在 Render 等公开静态环境只开放“从零建造”和“乐高实验”。
- 公开模式不请求、读取或展示 `dashboard/data.json`。
- 本地存在 `data.json` 时，保持 M1.9 的完整七视图能力。
- 在页面上明确标识“确定性教学模拟、不调用 API、不执行工具”。
- 提供可部署的 Render 静态站点配置和可重复验证命令。

## 3. 用户故事或实验场景

- 作为第一次了解 Agent 的访客，我希望打开链接后只看到能直接操作的课程和装配实验，而不是一排失效标签。
- 作为招聘方，我希望知道页面展示的是真实运行、教学模拟还是本地 Trace，避免把演示能力当成生产能力。
- 作为项目作者，我希望公开站点只发布 `dashboard/` 的静态代码，不意外上传真实 Eval 数据。
- 给定访客打开 Render 域名或带 `?demo=public` 的页面，当数据加载初始化时，则页面进入公开模式且不发起 `data.json` 请求。
- 给定本地 `127.0.0.1` 页面存在 `data.json`，当页面加载时，则保留完整七视图。

## 4. 范围

- 增加公开模式识别与页面状态。
- 在公开模式隐藏依赖真实 Trace 的导航和运行选择器。
- 调整课程数据状态卡和最终 CTA，使公开版只引导到可用的乐高实验。
- 增加 `render.yaml` 静态站点配置。
- 增加静态契约测试与浏览器验收记录。
- 更新 README、ROADMAP、规格索引和版本号。

## 5. 非目标

- 不生成、脱敏或发布真实 Trace。
- 不新增合成 Trace 冒充真实运行。
- 不改变 Agent runtime、工具、审批、上下文、压缩或 Eval。
- 不增加后端、数据库、API Key、网络工具或浏览器执行能力。
- 不评估公开展示对求职转化的真实效果。

## 9. 指标

- 公开模式不可用导航数量：0。
- 公开模式 `data.json` 网络请求：0。
- 公开模式可用交互视图：2（从零建造、乐高实验）。
- 本地回归可见视图：7。
- 控制台和页面错误：0。
- 桌面/移动端横向溢出：0。

上述为展示与可用性指标，不是 Agent 性能指标。

## 10. 安全与边界

- `dashboard/data.json` 继续由 `.gitignore` 排除。
- 公开模式在发起数据请求前返回，不读取本地或远端 Trace。
- Render 配置只发布 `dashboard` 静态资源，不启动 Python 服务。
- 页面不包含调用模型、执行工具或写文件的通道。
- “可审计性”等教学结论仍只描述固定模拟，不代表真实系统证据。

## 11. 风险与未决问题

- 风险：公开模式被误读为真实 Agent 已在线执行。缓解：页头、课程状态和乐高区同时声明“确定性教学模拟”。
- 风险：未来更换自定义域名后无法识别 Render 域名。缓解：保留 `?demo=public` 显式入口；部署链接使用该参数。
- 风险：本地无数据时仍保留真实视图入口用于查看导出说明。缓解：只有 `public` 状态隐藏入口，`missing` 本地状态保持教学提示。
- 待决：若未来需要公开真实 Trace，应单独设计脱敏白名单、人工审阅和可撤销发布流程。
