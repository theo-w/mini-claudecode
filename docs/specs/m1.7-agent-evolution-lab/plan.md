## 1. 方案摘要

在现有 Dashboard 前增加一个独立、数据无关的静态课程视图 `build`，作为默认入口。课程数据放在独立 UMD 模块 `dashboard/evolution.js`，页面渲染与交互继续由 `dashboard/app.js` 负责。现有真实 Trace 视图保持不变，作为完成基础课程后的“解剖真实运行”层。

课程采用 7 个单概念章节。每章使用固定的教学节奏：痛点 → 最小补丁 → 确定性输出 → 为什么有效 → 边界 → 检查题。第一版不执行代码，而是展示明确的确定性教学快照，避免把只读学习页扩展成未隔离的 Web Shell。

## 6. 测试策略

### 确定性测试

- 正常路径：7 章顺序固定，每章必需字段完整，检查题答案唯一。
- 语义路径：Tool 与 Skill 分开；Trace/Eval 边界；`SKIP != PASS`。
- 安全路径：页面源码不包含课程执行入口；安全章节不展示危险命令。
- 结构路径：HTML 包含 build 视图、7 章数据容器、导航和真实解剖入口。

### 浏览器 QA

- 默认进入 `从零建造`；
- 章节 01 → 07 可切换；
- 检查题错误/正确反馈；
- 390px 与 1440px 无横向溢出；
- 现有真实解剖入口仍可打开；
- console error / page error 为 0。

### Live Eval

不适用。本次不改变 Agent 行为、Prompt、工具协议或评测逻辑。

## 7. 安全与失败处理
