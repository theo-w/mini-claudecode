## 1. 背景与问题

M1.10 已把公开版收缩为“从零建造 + 乐高实验”，解决了真实 Trace 不可公开的问题。但公开页面默认仍直接进入 7 章课程，面试官或第一次访问者需要自行拼出以下信息：

- 这个项目解决谁的什么问题；
- 为什么不是再做一次 Claude Code；
- 7 章课程与 8 个可换零件之间是什么关系；
- 100 项测试究竟能证明什么，不能证明什么；
- 当前只是确定性教学模拟，还是已经验证了真实 Agent 效果；
- 3 分钟应该按什么顺序看，才能快速判断作者的产品与工程思路。

现有页面有深度，但缺少一个 **90 秒可读完、可继续操作的项目入口**。如果直接把课程或乐高工作台放在首屏，用户容易先看到“怎么玩”，却没有先理解“为什么做、验证了什么、还缺什么”。

本规格把公开版默认入口前移为“项目速览”，用一条问题 → 干预 → 分账的故事连接课程与实验，并明确划分工程、教学、Agent 效果和生产安全四层证据。

说明：HTML 叙事骨架先于本规格落地；本文件是在该骨架基础上回溯补齐 SDD 契约。后续入口状态、测试和验收均在实现记录完成前收敛。

## 2. 目标

- 公开版默认进入“项目速览”，让第一次访问者在首屏理解项目定位、核心假设与安全边界。
- 用三步故事解释“只有模型会撞墙 → 每次只加一个零件 → 分开判断完成、安全与审计”。
- 提供项目证据卡，集中回答目标用户、用户问题、假设、交付、工程证据和局限。
- 把工程正确性、教学有效性、Agent 效果、生产安全拆成四层证据，禁止用一个测试数字证明所有结论。
- 保留“从零建造”和“乐高实验”两个可操作入口；速览主按钮直接启动确定性基线，减少空转。
- 公开模式仍为零 Trace、零 API、零真实工具执行；本地完整七视图不回归。
- 保持桌面与手机可用，不依赖外部字体、图片、CDN 或后端。

## 3. 用户故事或实验场景

- 作为第一次访问公开链接的面试官，我希望在 90 秒内看懂项目定位、用户问题、核心假设和当前边界。
- 作为 Agent 初学者，我希望先看到一个失败基线，再选择“一键运行”或“从零建造”，而不是先背组件名词。
- 作为招聘方，我希望测试数字旁边就写明“只证明工程契约，不证明真实模型质量”。
- 作为学习者，我希望速览中的判断方式能自然过渡到乐高实验，看到完成度、执行边界和可审计性三本账。
- 作为项目作者，我希望本地有真实 `data.json` 时仍保留原有七视图，不因公开叙事破坏调试路径。
- 给定页面在 Render 域名或带 `?demo=public`，当页面初始化时，则默认显示“项目速览”，且不请求 `data.json`。
- 给定页面在本地完整模式，当 `data.json` 就绪时，则默认仍显示“从零建造”，且速览标签不可见。

## 4. 范围

- 在页头增加仅公开模式可见的“项目速览”入口。
- 增加 90 秒项目定位、三步故事、项目证据卡、四层证据与面试讲解路线。
- 扩展公开视图状态机：`brief / build / lego` 三个合法入口。
- 速览主 CTA 切换到乐高并立即运行一次空装配基线；次 CTA 切换到从零建造。
- 增加桌面与移动端响应式样式。
- 增加静态契约测试与 Playwright 桌面/手机验收。
- 更新 README、ROADMAP、规格索引和版本号。
- 记录 Render 线上部署与入口复核结果。

## 5. 非目标

- 不调用真实模型 API，不新增后端、API Key 或在线执行。
- 不执行真实工具、Shell、文件写入或子进程。
- 不读取、生成、脱敏或发布真实 Trace、Observation 或最终回答。
- 不把确定性教学模拟描述为真实任务成功率。
- 不证明教学有效性，不开展用户实验或求职转化实验。
- 不新增 Skill、Memory、MCP、RAG、Subagent、多 Agent 或在线评测平台。
- 不把 100 项确定性测试解释为 Agent 可靠性证明。
- 不重构真实 Harness runtime、工具 Schema、审批或 Eval。

## 9. 指标

- 首屏项目定位：公开模式无需滚动即可看到标题、核心假设、主 CTA 与安全边界。
- 公开入口数量：3 个（Brief / Build / Lego）。
- 公开 Trace 请求：0。
- 公开执行通道：0。
- 本地可见视图：7 个。
- 横向溢出：1440px 与 390px 均为 0px。
- 确定性测试：100 项通过。
- 基线教学结果：`BLOCKED / UNKNOWN / NONE`。

这些是展示与工程契约指标，不是 Agent 成功率、教学效果或生产安全指标。

## 10. 安全与边界

- 本变更只修改静态 HTML/CSS/JavaScript、测试和文档。
- 公开模式在数据加载前短路，不读取 `dashboard/data.json`。
- Render 只发布 `dashboard/`；`dashboard/data.json` 仍在 `.gitignore` 中。
- 速览 CTA 只启动页面内 `Lego.simulateRun()` 的确定性模拟，不调用模型、不执行工具。
- “公开版零执行通道”只说明页面没有执行入口，不代表生产级隔离、权限、配额或稳定性已经验证。
- 工程测试只证明契约、边界和确定性数据逻辑，不证明真实模型质量或教学有效性。

## 11. 风险与未决问题

- 风险：证据卡再次变成密集文字，降低 90 秒可读性。缓解：首屏只保留定位、假设、主 CTA 和边界；细节按故事、卡片、路线分层。
- 风险：100 项测试被误读为 Agent 效果。缓解：测试数字旁明确写“验证工程契约，不等于验证真实模型质量”，并使用四层证据表。
- 风险：公开版改动破坏本地七视图。缓解：用独立的公开状态机和本地回归测试隔离入口。
- 风险：手机端按钮或长代码串造成横向溢出。缓解：390px Playwright 检查 `scrollWidth <= clientWidth`，代码串允许换行。
- 待决：教学有效性和真实 Agent 效果必须进入后续用户实验与 M2 固定评测，不能由本次页面改动代替。
