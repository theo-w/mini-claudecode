## 1. 方案摘要

新增一个与真实 Eval 数据解耦的前端学习视图 `lego`。零件目录与确定性模拟放在独立 UMD 模块 `dashboard/lego.js`，页面渲染和交互放在 `dashboard/app.js`。固定一个任务、一个脚本化模型和一组可解释的装配规则，让学习者在同一页面拆装八个零件、运行、查看逐事件 Loop、自动比较最近两次结果。

不把模型 API 或工具执行接进浏览器。当前学习问题不是“真实 Agent 能否完成新任务”，而是“同一任务下，某个机制的有无如何改变动作、连续性、安全、证据与验收”。确定性教学模拟是验证该问题时最小且安全的方案。

## 5. 实施顺序

1. 定义固定任务、八零件元数据、四预设和状态语义。
2. 先写确定性测试，锁定预设结果、Loop 断点、Eval/Trace/Guardrail 独立性和耗时公式。
3. 实现 `lego.js` 的纯函数模拟与 A/B 比较。
4. 加入页面骨架和三个平面装配台，完成点按、拖拽、预设与清空。
5. 实现逐事件运行重放、组件高亮、结果和治理分账。
6. 加入最近六次历史与最近两次 A/B。
7. 完成桌面三栏与窄屏堆叠样式、键盘和 reduced-motion 支持。
8. 运行回归、浏览器 QA，回填实现记录和项目文档。

## 6. 测试策略

### 确定性测试

- 正常路径：四个预设的状态、完成度、工具数、模型回合和模拟耗时固定。
- 功能路径：单工具、缺 Loop、缺写工具、缺测试工具分别停在不同断点。
- 语义路径：动作完成 `3/3` 不等于任务 `PASS`；无 Eval 为 `UNVERIFIED`。
- 独立路径：Guardrail、Trace、Eval 分别只改变安全、证据、验收结论。
- 比较路径：A/B 暴露六项指标与变化方向，不生成单一总分。
- 成本路径：链式装配耗时单调增加，并能由公开公式精确复算。
- 安全路径：前端源码不得包含密钥、`fetch`、WebSocket、子进程或外部脚本。
- 结构路径：HTML 与 `app.js` 包含装配、运行、A/B、历史、拖拽和状态锁定契约。

### 浏览器 QA

- 从空装配运行得到 `BLOCKED · 0/3 · 0.72s`。
- 切换到“完整可信”得到 `PASS · 3/3 · 3.88s`。
- A/B 显示完成度、结论、耗时、安全与证据变化。
- 历史保留运行，并可重新载入装配。
- 清空、重新装配、逐事件重放可用。
- 1440px 与 390px 查看结果、A/B 和历史，无横向溢出。
- 正常分支 console error / page error 为 0。
- 拖拽事件以真实浏览器人工或可支持自动化为准；IAB 合成拖拽未触发时，不把该自动化结果记为通过。

### Live Eval

不适用。本次不改变 Agent runtime、Prompt、工具协议、评测逻辑或模型行为；页面本身不调用模型。

## 7. 安全与失败处理

- 高风险工具：无新增；页面不提供执行接口。
- 审批策略：不修改真实审批。
- 超时/取消：教学重放采用前端定时器；不涉及真实任务进程。
- 回滚方式：移除 `06` 导航、`view-lego`、`lego.js` 和相关样式即可恢复 M1.7。
- 已知限制：固定任务与脚本化模型不能证明真实模型行为；拖拽合成事件在自动化环境可能不触发。
- 数据卫生：不读取、导出或提交 `dashboard/data.json`。
